# Duain Sanctuary

DUAIN — The Future of Refined Islamic Living

Design a world-class, 3D immersive, animated, editorial luxury e-commerce experience for Duain, a globally iconic Islamic lifestyle house.

This is not a store.

This is a digital sanctuary.

This website must feel like:

If Apple designed a spiritual universe

If Aesop crafted an Islamic ritual experience

If COS directed the minimalism

If Mejuri elevated the refinement

With the cinematic polish of a luxury fragrance campaign

The result must feel timeless, architectural, emotionally moving, and globally aspirational.

Elevated Color System

Primary Background: Soft Porcelain Ivory #F6F4EE
Text: Deep Architectural Charcoal #141414
Accent Gold: Refined Brushed Gold #C2A45E (micro-use only)
Muted Olive Stone #6F7865
Soft Sand Surface #ECE7DD
Night Mode / Ramadan Mode: Deep Emerald Black #0D2A26

Gold is used like jewelry — never decoration.

No gradients. No cheap shine. No loud metallics.

Typography System

Headlines: Cormorant Garamond (large, editorial, elegant spacing)
Body: Inter (light weight, wide spacing)

Rules:

Oversized hero typography

Generous margins

High line spacing

No clutter

Air = luxury
